# CSCE 477 Secure Login Form

This project is a simple login form created for a HW 2 in CSCE 477

## Features

- Email input
- Password input
- Client-side validation
- Server-side validation
- Email must contain @
- Password must contain at least 8 characters
- Empty submissions are rejected
- User-controlled output is displayed using textContent

## Running the Project

1. Clone this repository.
2. Install Node.js.
3. Run:

   npm install

4. Start the server:

   npm start

5. Open:

   http://localhost:300
